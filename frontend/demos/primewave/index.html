Integrations · Frigate NVR

Base URL of your Frigate server. The AI Center → Playground page reads the camera list from <url>/api/config and pulls snapshots from <url>/api/<camera>/latest.jpg. Shared across all demos on this VM.

Integrations · WhatsApp (WasenderApi)

WasenderApi credentials for the Call Center → WhatsApp page. Get them from wasenderapi.com: API Key from your paired WhatsApp session (Settings → WhatsApp Sessions); Personal Token from Settings → Personal Access Tokens (optional, only needed for the outbound message logs API).
Configure your WhatsApp session in WaSender to POST every incoming message to this URL. Master Basic Auth is bypassed for this path so WaSender can reach it.

Integrations · Supervisor Escalation

When the Live Agent raises a red flag during a call, the Dashboard shows an indicator and you can click Engage supervisor to ring the configured extension and drop them into the live call via FreePBX ChanSpy. Asterisk Manager Interface (AMI) credentials below come from /etc/asterisk/manager.conf on your PBX.

Call Center · Configuration

Noura's persona + knowledge base. Both are read from disk on every call — no restart required after Save.

Persona

Tone, language, identity rules, intake flow, and what the agent will / won't do.

Knowledge base

Facts the agent uses as context during a call (services, protocols, coverage, pricing policy).

Tools

Functions the Live Agent can call during a conversation. The agent decides when to call each based on the persona's instructions. Read-only — to add or remove tools, edit _build_tools() in backend/app/demos/primewave/live_agent.py.
